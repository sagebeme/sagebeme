## Selected work

*Client details generalised.*

**Custodial synthetic-index trading platform**
Next.js + NestJS + TypeScript, PostgreSQL/TypeORM, Redis, Docker. Internal wallets funded by M-Pesa, cards and crypto. Digit-option and Rise/Fall contracts priced off a live WebSocket feed, fanned out to every connected browser from a single upstream subscription per symbol. Hand-rolled inline SVG line and candlestick charts — no charting library. Idempotent deposits and withdrawals with debit-then-reverse-on-failure, a KYC review queue, scheduled ledger reconciliation against the live account balance, and an audited admin console with role elevation, payout freeze, investigation hold and immediate token revocation.

**Nyumbani Manager** — rental tenancy & rent tracking
React 18, TypeScript (strict), Supabase with row-level security. Money is an integer number of cents end to end; rent cycles run in Nairobi time; arrears ageing, rent roll, CSV export and printable monthly statements. Access rules are tested as real SQL executed as tenant, landlord, admin and signed-out visitor — plus mutation tests that break each database protection one at a time and confirm the suite notices. WCAG AA throughout, verified with axe inside Playwright journeys at phone and desktop width.

**Verido** — multi-tenant agricultural supply-chain SaaS
Frontend for a platform spanning Kenya, Nigeria, Uganda, Mozambique and Ghana. Facilitator dashboard over real-time API data, plus user flows and matchmaking features. React and Node.js.

**Mobile-money bundle reseller**
Flutter targeting Android, iOS and web from one codebase, with a Node/Express backend. M-Pesa Daraja STK Push guarded by an order state machine and a money-in/goods-out reconciliation sweep.

**Algorithmic trading EA**
MetaTrader 4 and 5 (MQL4/MQL5). A market-structure methodology compiled from a deterministic rule spec, backtested and walk-forward validated.
